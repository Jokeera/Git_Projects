# Нажатие клавиши по звуку

Скрипт слушает микрофон и нажимает клавишу **G**, когда слышит резкий звук —
хлопок, щелчок, всплеск воды и т.п. Можно реагировать на любой резкий звук
или только на те, примеры которых вы записали.

## Установка

1. Установите Python 3.9+ (на Windows при установке отметьте «Add Python to PATH»).
2. В папке со скриптом:
   ```
   pip install -r requirements.txt
   ```

## Использование

```
python sound_trigger.py devices            # какие есть микрофоны
python sound_trigger.py levels             # индикатор громкости — понять, какой порог ставить
python sound_trigger.py run                # G на ЛЮБОЙ резкий звук (без задержки)
```

Реагировать только на конкретный звук:

```
python sound_trigger.py record splash -n 5          # 5 раз плеснуть водой
python sound_trigger.py record clap -n 5            # 5 раз хлопнуть
python sound_trigger.py run --match splash          # G только на всплеск
python sound_trigger.py run --match splash clap     # на всплеск или хлопок
```

## Настройка

| Параметр | Что делает |
|---|---|
| `--threshold -35` | Минимальная громкость (дБ). Срабатывает от тихих звуков — поднимите (`-25`); не срабатывает — опустите (`-45`). Смотрите значения в `levels`. |
| `--margin 15` | На сколько дБ звук должен быть громче фонового шума. |
| `--similarity 0.7` | Насколько звук должен быть похож на образец (0..1). Ложные нажатия — поднимите, пропуски — опустите. Скрипт печатает похожесть каждого звука. |
| `--cooldown 0.5` | Минимальная пауза между нажатиями (сек). |
| `--key g` | Какую клавишу жать (`f`, `space`, ...). |
| `--device 3` | Какой микрофон использовать. |
| `--directinput` | Для игр, которые не видят нажатия (Windows): `pip install pydirectinput`. |

## Заметки

- Без `--match` нажатие мгновенное; с `--match` — задержка ~0.35 с (звук надо дослушать, чтобы сравнить).
- Записывайте образцы в том же месте и тем же микрофоном, где будете использовать.
- Если игра запущена от администратора, скрипт тоже нужно запустить от администратора.
- macOS: разрешите терминалу доступ к микрофону и «Универсальный доступ» (для нажатия клавиш).
